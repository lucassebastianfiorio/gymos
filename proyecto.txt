================================================================================
ESTRUCTURA MONOREPO
================================================================================

/gymos-monorepo
 ├─ apps/
 │    ├─ web/              ← frontend Next.js (shadcn dashboard)
 │    └─ api/              ← NestJS backend (tenants, auth, APIs)
 ├─ packages/
 │    ├─ ui/               ← componentes Shadcn + custom
 │    ├─ contracts/        ← types / interfaces TS compartidos
 │    └─ utils/            ← helpers
 └─ .env

Regla: Todo funciona sin backend y sin IA, después se conecta con Nest y módulos de IA.

PRINCIPIOS CLAVE
================================================================================
1. Front-first: todo mock, UI lista antes de backend real
2. Tenants first: AdminGlobal define reglas, features y permisos
3. Escalable: cada módulo (socios, pagos, clases) se conecta después
4. IA opcional: toggle global y por tenant, sin romper UX
5. RBAC completo: roles y menús dinámicos
6. Branding y dark/light listos desde el inicio
